# Página Web del Colegio

Proyecto final de la materia Diseño de Interfaz, desarrollado durante 2024.

## Descripción

El proyecto consiste en el diseño y desarrollo de una página web institucional para el colegio.

El objetivo fue aplicar los conocimientos adquiridos durante la materia, trabajando en la estructura visual de la página, la organización de los contenidos, la navegación y la presentación de la información.

## Diseño de Interfaz

Durante el desarrollo se trabajaron aspectos relacionados con:

- Diseño y organización de la interfaz.
- Distribución y presentación de contenidos.
- Navegación entre las diferentes secciones.
- Estructura visual de la página.
- Experiencia de usuario.

## Tecnologías utilizadas

- HTML
- CSS
